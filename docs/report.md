## Обработка данных о покупателях

### Индивидуальное задание
Вывести данные о покупателях города Брест.

### Структура данных
Программа работает со следующей информацией о покупателе:
- Фамилия, имя, отчество
- Пол, национальность
- Рост, вес
- Дата рождения
- Номер телефона
- Домашний адрес (почтовый индекс, страна, область, район, город, улица, дом, квартира)
- Номер кредитной карточки
- Номер банковского счета

### Реализация
Программа реализована в соответствии с моделью КИС:
- **Модуль file_handler**: отвечает за создание файлов и отображение содержимого
- **Модуль data_processor**: выполняет парсинг данных и фильтрацию покупателей из Бреста
- **Главный модуль main**: координирует работу всех модулей

### Тестирование

#### Тест 1: Создание файла с данными
- **Действие**: Запуск программы
- **Ожидаемый результат**: Создание файла data/customers.txt с 10 записями о покупателях
- **Фактический результат**: ✓ Файл создан успешно

#### Тест 2: Чтение и отображение данных
- **Действие**: Программа выводит содержимое файла
- **Ожидаемый результат**: Корректное отображение всех записей
- **Фактический результат**: ✓ Данные отображаются правильно

#### Тест 3: Фильтрация покупателей из Бреста
- **Входные данные**: 10 записей о покупателях (5 из Бреста, 5 из других городов)
- **Ожидаемый результат**: Вывод только 5 записей покупателей из Бреста
- **Фактический результат**: ✓ Отфильтровано 5 покупателей

### Выводы
Программа успешно выполняет поставленную задачу:
1. Создает файл с данными о покупателях согласно индивидуальному заданию
2. Читает и отображает содержимое файла
3. Фильтрует данные, выбирая только покупателей из города Брест
4. Сохраняет отфильтрованные данные в новый файл с форматированным выводом
5. Добавляет статистическую информацию о количестве покупателей и распределении по полу

Программа соответствует требованиям:
- Использует модель КИС (разделение на модули)
- Имеет Makefile для автоматизации сборки
- Включает тесты для проверки работоспособности
- Документирована и имеет понятную структуру
