# Overview
Программа для обработки данных о покупателях. Выполняет чтение данных из CSV файла, фильтрацию покупателей по городу (Брест) и сохранение результатов в новый файл с форматированным выводом и статистикой.

## Data Format

### Input File (customers.txt)
CSV формат с полями:
- Фамилия, Имя, Отчество, Пол, Национальность
- Рост, Вес, Дата рождения, Телефон
- Индекс, Страна, Область, Район, Город, Улица, Дом, Квартира
- Номер карты, Номер счета

### Output File (brest_customers.txt)
Отформатированный вывод, содержащий:
- Данные покупателей из Бреста
- Общее количество найденных покупателей
- Статистику по полу
