## Overview
Программа для обработки текстовых файлов, выполняющая чтение, обработку данных и запись результатов в новый файл. Реализована на языке C с использованием модели КИС.

## Usage
### Сборка проекта
```bash
make
```

### Запуск программы
```bash
./bin/file_processor
```

Программа выполняет следующие действия:
1. Создает текстовый файл с произвольной информацией
2. Отображает содержимое файла
3. Обрабатывает данные согласно индивидуальному заданию
4. Сохраняет результаты в новый файл

### Очистка
```bash
make clean
```

## Additional Notes
- Структура проекта соответствует модели КИС
- Для сборки требуется GCC и Make
- Программа использует стандартные библиотеки C
